# 画像・素材について（ダークテーマ版）

デザインは漆黒ベースのダーク／エディトリアル。装飾は**CSSとインラインSVGアイコン**で構成し、
重い画像に依存しない設計です。同梱画像は最小限です。

## 同梱アセット

| ファイル | 用途 |
|---|---|
| `logo.svg` | ロゴ（ライト文字＋ライムのマーク／ヘッダー・フッター共通） |
| `favicon.svg` | ブラウザタブのアイコン（ダーク＋ライム） |

そのほかのビジュアル要素：
- アイコン … 各ページに**インラインSVG**（`stroke="currentColor"` で配色追従）
- 質感 … ノイズ（CSSのSVGデータURI）／ヘアライン罫線／ライムのグロー
- 流れる帯（マーキー）／アウトライン特大文字 … CSSのみ

## 写真を入れたい場合（推奨：御社スタッフ・施工写真）

各ページの `.media`（シネマティックな枠）に、御社の実写を入れるとさらに引き締まります。
枠は `object-fit:cover` でフィットし、軽いグレースケール＋コントラスト補正がかかります。

```html
<!-- 変更前（プレースホルダ） -->
<div class="media" data-label="On-site / 施工"><span class="ic">…icon…</span></div>
<!-- 変更後（写真を入れるだけ） -->
<div class="media"><img src="images/photo.jpg" alt="施工の様子"></div>
```

推奨サイズの目安：`.media` 4:3（例 1000×750px）／`.media--wide` 16:9 ／ `.media--tall` 3:4。
会社概要のアクセスは `company.html` の `.map` を Google マップ埋め込み `<iframe>` に置換してください。

## アクセントカラーの変更
`css/style.css` の `:root` 内 `--acc`（既定 `#c8f24a` ライム）を変えるだけで全体の差し色が変わります。

## ライセンス
ロゴ・favicon・アイコンはすべて本プロジェクト用に新規制作したオリジナルです。
