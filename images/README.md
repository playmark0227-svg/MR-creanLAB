# 画像 manifest（差し替えリスト）

リモート実行環境のネットワーク制限により、元サイト（https://mrcleanlab.co.jp/）から
画像を直接ダウンロードできませんでした。各ページの画像は HTML 内で
**プレースホルダ（`.ph`）**として「何の画像か」を明記しています。

実物を入れる場合は、元サイトから取得した画像をこの `images/` フォルダに置き、
対応するプレースホルダ `<div class="ph">…</div>` を `<img src="images/ファイル名" alt="...">` に
差し替えてください。
