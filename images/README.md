# 画像・イラスト素材について

このサイトの画像は、ネット制限・ライセンスの都合により**すべてオリジナルのSVGイラスト**で
制作しています（ストック写真は不使用）。ベクターなので拡大しても劣化せず、配色は
`css/style.css` の `:root` 変数と連動して調整できます。

## 実写に差し替えたい場合（推奨：御社スタッフ・実際の施工写真）

実在のストック人物写真より、**御社の実際のスタッフ写真・施工写真（before/after）**を
入れる方が信頼感が高くおすすめです。差し替えは簡単です。

- サービスカードの画像差し替え例：
  ```html
  <!-- 変更前 -->
  <div class="service-card__media"><img class="ill" src="images/art-pest.svg" alt=""></div>
  <!-- 変更後（写真をそのまま入れるだけ。比率4:10の枠に自動でフィット） -->
  <div class="service-card__media"><img src="images/写真ファイル名.jpg" alt="害虫駆除の施工"></div>
  ```
  ※ `class="ill"`（イラスト用の縮小表示）を外すと、写真が枠いっぱいに `cover` 表示されます。

- 各画像枠の推奨サイズ（目安）
  - サービスカード `service-card__media`：16:10（例 800×500px）
  - お客様の声 `voice__media`：4:3（例 640×480px）
  - 施工写真 `media-frame`：4:3
  - ヒーロー `hero__art` / 各 `art-*.svg`：差し替え時は縦長〜正方形のビジュアル推奨

- 会社概要のアクセスマップ：`company.html` の `.map-embed` を Google マップの
  埋め込み `<iframe>` に置き換えてください。
