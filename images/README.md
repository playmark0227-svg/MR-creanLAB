# 画像差し替えガイド（顔写真・施工写真）

各ページのプレースホルダ（点線の枠）には **画像を入れる受け皿** を仕込み済みです。
下記のファイル名で画像を生成（またはご用意）して、この `images/` フォルダに置くだけで表示されます。
**ファイルが無い／名前が違う場合は、自動で今のプレースホルダ表示に戻る**ので壊れません。

- jpg / png どちらでも可（透過不要なら jpg 推奨）。
