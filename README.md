# MR.Clean Lab サイト再現プロジェクト

株式会社MR.クリーンラボ（https://mrcleanlab.co.jp/ ）のサイトを、提供された
スクリーンショットを元に **静的HTML/CSS で再構築**したものです。
今後のデザイン改造（リニューアル）のベースとして使用します。

> サイト所有者の許諾のもとで、改造作業用にコピーしています。

## 確認・閲覧方法

ビルド不要。ブラウザで `index.html` を開くだけで確認できます。
ローカルサーバで見る場合：

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

※ `404.html` は公開URL（`/MR-creanLAB/`）を基準に読み込むよう固定しています。ローカルで404ページまで確認する場合は、
リポジトリの**親フォルダ**でサーバを起動し `http://localhost:8000/MR-creanLAB/` を開いてください。
独自ドメインの直下で公開する場合は、`404.html` の `<base href="/MR-creanLAB/">` を `<base href="/">` に変更します。

## 再現の前提・注意点（要確認箇所）

ネット取得がブロックされていたため、**スクリーンショットからの目視再現**です。
以下は実サイトと突き合わせて確認・修正してください。

1. **画像**：写真・ロゴは `images/` に配置済み。差し替え方法は `images/README.md` を参照。
2. **小さい本文テキスト**：サービス説明やお客様の声など文字が小さい箇所は
   読み取れた範囲での再現です。「（要確認）」と記載した箇所は要チェック。
3. **お問い合わせフォーム**：送信先（Formspree等のURL）を `js/main.js` の
   `MRCL_FORM.ENDPOINT` に設定すると送信できるようになります（未設定の間は電話をご案内）。
4. **配色・フォント・余白**：スクショからの近似値です（`css/style.css` の
   `:root` 変数で一括調整可）。
5. **ロゴ**：最新ロゴ（`images/logo.svg` ほか一式）に全ページ統一済み。詳細は `images/README.md`。
