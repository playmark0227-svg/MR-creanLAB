# MR.Clean Lab サイト再現プロジェクト

株式会社MR.クリーンラボ（https://mrcleanlab.co.jp/ ）のサイトを、提供された
スクリーンショットを元に **静的HTML/CSS で再構築**したものです。
今後のデザイン改造（リニューアル）のベースとして使用します。

> サイト所有者の許諾のもとで、改造作業用にコピーしています。

## ページ構成

| ファイル | 内容 | 取得元 |
|---|---|---|
| `index.html` | ホーム | スクショあり |
| `pest-control.html` | 害虫害獣 駆除・防除 | スクショあり |
| `drainage.html` | 排水管洗浄・グリーストラップ清掃 | スクショあり |
| `reform.html` | リフォーム・ハウスクリーニング | スクショあり |
| `company.html` | 会社概要（代表メッセージ・会社概要テーブル） | スクショあり |
| `news.html` | お知らせ一覧 | ホームのお知らせ3件から再現 |
| `contact.html` | お問い合わせフォーム | **スクショ未取得**・一般構成で仮作成 |
| `css/style.css` | 全ページ共通スタイル（CSS変数で配色調整可） | — |
| `images/README.md` | 必要画像の差し替えリスト | — |

## 確認・閲覧方法

ビルド不要。ブラウザで `index.html` を開くだけで確認できます。
ローカルサーバで見る場合：

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

## 再現の前提・注意点（要確認箇所）

ネット取得がブロックされていたため、**スクリーンショットからの目視再現**です。
以下は実サイトと突き合わせて確認・修正してください。

1. **画像**：すべてプレースホルダ。`images/README.md` の一覧を参照し差し替え。
2. **小さい本文テキスト**：サービス説明やお客様の声など文字が小さい箇所は
   読み取れた範囲での再現です。「（要確認）」と記載した箇所は要チェック。
3. **お問い合わせページ**：スクショが無いため一般的なフォームで仮作成。
   実際の項目・送信先に差し替えてください。
4. **配色・フォント・余白**：スクショからの近似値です（`css/style.css` の
   `:root` 変数で一括調整可）。
5. **ロゴ**：CSSテキストで簡易再現。正式ロゴ画像に差し替え推奨。
